# WaveX

Десктопный музыкальный плеер для Windows: ВКонтакте, YouTube, SoundCloud, Яндекс Музыка и Spotify — без рекламы и ограничений.

![Платформа](https://img.shields.io/badge/платформа-Windows%2010%2F11-blue)
![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![Лицензия](https://img.shields.io/badge/лицензия-MIT-green)

## Возможности

- Прослушивание аудиозаписей из каталога ВК без рекламы и ограничений
- Поиск сразу по пяти сервисам: ВКонтакте, YouTube, SoundCloud, Яндекс, Spotify
- Минималистичный интерфейс (тёмная и светлая темы), полноэкранный режим плеера
- Эквалайзер (5 полос, пресеты), скорость (0.5–2×) и тон (±12 полутонов) — кнопка «EQ» в панели плеера
- Скачивание треков и целых плейлистов в MP3 с ID3-тегами и обложками
- Поддержка прокси (HTTP/SOCKS5) с автоподбором долгоживущих серверов — для стран, где ВК не открывается
- Кеширование треков с разделением на подкасты и плейлисты; папку хранилища можно перенести на любой диск
- Обложки в высоком качестве (до 1200×1200 из ВК, фолбэк — iTunes) и тексты песен (Genius, фолбэк — ВК, lyrics.ovh, LRCLIB)
- Глубокая интеграция ВК: каталог, подсказки поиска, популярное, рекомендации, плейлисты, подкасты
- Профиль не уходит в «онлайн»: используются только методы `audio` и `users.get`
- Сворачивание в системный трей при закрытии окна (музыка продолжает играть; в настройках отключается)
- Небольшой вес и минимальное потребление трафика (кеш переиспользуется)

## Установка

### Запуск из исходников

Требуется Python 3.10+.

```
py -m pip install -r requirements.txt
py main.py
```

Если команда `python` не работает («Python was not found… Microsoft Store»), используйте
`py` вместо `python`, либо отключите алиас: Параметры → Приложения → Дополнительные
параметры → Псевдонимы выполнения приложений.

### Сборка exe самостоятельно

```
build.bat
```

Результат: `dist\WaveX.exe` (копия автоматически кладётся на рабочий стол).
Только так пока что.
## Вход

При первом запуске доступны три способа входа:

- Войти через ВК (браузер) — окно авторизации ВК;
- Вход по логину и паролю (рекомендуется)** — flow официального клиента ВК, данные уходят напрямую на серверы ВК и нигде не сохраняются, кроме полученного токена;
- Ввести токен вручную — вставить готовый access_token или адрес страницы `blank.html#access_token=...`.

Токен сохраняется локально (`%APPDATA%\WaveX\config.json`).

## Другие сервисы

В поиске есть переключатель сервисов: **ВКонтакте, YouTube, SoundCloud, Яндекс, Spotify**.

- YouTube / SoundCloud — работают сразу (через yt-dlp). Для конвертации в MP3 нужен ffmpeg: Настройки → «Установить ffmpeg» (скачивается автоматически в `%APPDATA%\WaveX\bin`).
- Яндекс Музыка — нужен OAuth-токен (инструкция в Настройки → Сервисы).
- Spotify — нужны Client ID/Secret с developer.spotify.com. Полные треки без Premium недоступны: играется 30-секундное превью или соответствие с YouTube.

## ffmpeg (для части треков)

Некоторые треки ВК и большинство треков сторонних сервисов отдаются не в MP3.
ffmpeg можно установить кнопкой в настройках, либо вручную
(сборка для Windows: https://www.gyan.dev/ffmpeg/builds/ — нужен `ffmpeg.exe` в PATH).
Без ffmpeg HLS-потоки ВК склеиваются без перекодирования.

## Прокси

Настройки → Прокси. Формат: `http://host:port` или `socks5://host:port`
(например, `socks5://127.0.0.1:9050`).

Есть автоподбор: кнопка «Подобрать прокси» на экране входа или в настройках
скачивает списки бесплатных прокси из нескольких источников, проверяет доступность
ВК через каждый и выбирает лучший. База проверенных прокси хранится в
`%APPDATA%\WaveX\proxies.json` — приоритет отдаётся «долгоживущим» прокси
(те, что стабильно проходят проверки от обновления к обновлению). Если активный
прокси падает, приложение автоматически переключается на следующий из базы.
Ручной прокси имеет приоритет над автоподобранным.

## Файлы

- Настройки и кеш: `%APPDATA%\WaveX\` (папку кеша можно сменить в настройках)
- Скачанные треки: `Музыка\WaveX` (меняется в настройках)
- Лог ошибок: `%APPDATA%\WaveX\error.log`
